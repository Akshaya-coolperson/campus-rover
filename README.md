   ## What it will do by Week 12 (acceptance criteria)
   - [ ] Measures distance ahead and slows as an obstacle approaches
   - [ ] Stops before hitting an obstacle, sweeps its sensor head and turns toward the clearest direction
   - [ ] Reports distance, temperature/humidity, light and motion to a cloud dashboard every few seconds
   - [ ] Obeys STOP / DRIVE / HONK commands sent from the dashboard
   - [ ] Runs a 3-minute demo on battery without resetting
